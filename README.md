# SafeRoadAI
SafeRoadAI is an intelligent road safety prediction system designed to help users assess real-time travel risks based on factors like weather, traffic density, road geometry, and driver behavior patterns. The system takes a location input and provides a detailed prediction including a safety score, risk level, and nearby danger zones. It uses a machine learning pipeline trained on multi-feature accident data and is deployed with a user-friendly web interface for easy interaction. Although it's not a full-fledged mobile app yet, users can search for any location directly through the interface and get instant insights on potential travel risks. The aim is to assist commuters in making safer travel decisions and visualize risk in an intuitive way.
