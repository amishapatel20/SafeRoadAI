# SafeRoadAI
This project provides an end-to-end machine learning pipeline for predicting road accident casualty severity using real-world Excel data. It covers data loading, preprocessing (label encoding, datetime conversion, scaling), feature-target separation, and stratified train-test splitting. Class imbalance is handled using SMOTE to improve model fairness. Multiple models—including Random Forest, Neural Network, SVM, Logistic Regression, KNN, Gradient Boosting, and XGBoost—are trained and evaluated using accuracy and F1-score. Hyperparameter tuning is performed using GridSearchCV to optimize performance. The best-performing model is then integrated into a user-friendly Streamlit web app, enabling real-time prediction of casualty severity based on user inputs, making the system both effective and deployable.
